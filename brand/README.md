# Identidade Visual — Peladeiros Diferenciados

Material-fonte da marca. Arquivos aqui são a **origem**; as versões consumidas pela
aplicação vivem em `src/assets/` (emblema/ícone de login) e em `public/` (favicon).

## Arquivos

| Arquivo | Uso |
|---------|-----|
| `emblem-peladeiros-transparent.png` | Emblema com fundo transparente (login/telas) |
| `logo-peladeiros.svg` / `.png` | Logo vertical |
| `logo-peladeiros-horizontal.svg` / `.png` | Logo horizontal |
| `icon-peladeiros.svg` / `icon-peladeiros-512.svg` | Ícone vetorial (app/PWA) |
| `icon-peladeiros-192/512/1024.png` | Ícones rasterizados (PWA / lojas) |
| `favicon.ico` | Favicon (cópia em `public/favicon.ico`) |

Ao atualizar a marca, edite os SVGs aqui e re-exporte os PNGs/favicon.
